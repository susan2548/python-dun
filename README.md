# Python Dungeon

เกมดันเจี้ยน 2D แนว turn-based RPG สำหรับฝึกเขียน Python ตั้งแต่ `print()` และตัวแปร ไปจนถึงฟังก์ชัน คลาส และการจัดการข้อผิดพลาด ผู้เล่นเลือกนักผจญภัย อัศวิน หรือพ่อมด แล้วเขียนโค้ดเพื่อโจมตีมอนสเตอร์

**เล่นเกม:** https://python-dungeon-live.vercel.app/

## เริ่มพัฒนาบนเครื่อง

โปรเจ็กต์นี้เป็นเว็บแบบ static ไม่ต้องติดตั้งแพ็กเกจ npm แต่ต้องใช้อินเทอร์เน็ตเพื่อโหลด Pyodide และฟอนต์

```bash
git clone https://github.com/susan2548/python-dun.git
cd python-dun
python -m http.server 8000
```

เปิด `http://localhost:8000` ในเบราว์เซอร์ อย่าเปิด `index.html` ด้วย `file://` เพราะ Web Worker และ ES modules ต้องโหลดผ่านเว็บเซิร์ฟเวอร์

## ไฟล์สำคัญ

| ไฟล์                | หน้าที่                                                   |
| ------------------- | --------------------------------------------------------- |
| `index.html`        | โครงหน้าเว็บ                                              |
| `styles.css`        | หน้าตาเกมและการแสดงผลบนมือถือ                             |
| `game.js`           | แผนที่ ตัวละคร ระบบต่อสู้ ร้านค้า และความคืบหน้า          |
| `curriculum.js`     | โจทย์ 18 ข้อ คำใบ้ และคำอธิบายหลังตอบถูก                  |
| `python-worker.mjs` | รัน Python ด้วย Pyodide และตรวจคำตอบของแต่ละโจทย์         |
| `audio-engine.js`   | สร้างเพลงชิปจูนแยกแต่ละชั้นและเสียงเอฟเฟกต์ด้วย Web Audio |
| `sprite-motion.js`  | แคชเฟรมท่ายืนแบบ raster โดยตรึงเท้าและขยับลำตัว/ผ้าคลุม |
| `assets/`           | ภาพฉาก ตัวละคร และมอนสเตอร์                               |

## วิธีเล่นและกติกา

- แต่ละชั้นมี 3 โจทย์ ต้องเขียนคำตอบใหม่ทุกข้อ
- โค้ดต้องรันได้จริงและผ่านการตรวจทั้งผลลัพธ์และโครงสร้างที่โจทย์กำหนด
- ใช้ `attack(พลัง)` หรือ `skill("ชื่อสกิล", พลัง)` หนึ่งคำสั่งต่อข้อ โดยพลังเป็นจำนวนเต็ม 1–3
- HP/MP คงเหลือต่อเนื่องทุกชั้น การกลับแผนที่หรือรีโหลดรักษาสถานะการต่อสู้เดิม
- พักแรมเสีย 30 เหรียญ ฟื้นสูงสุด 55 HP และ 6 MP; ซื้อยามานาได้ในร้านค้า
- ผ่านครบ 3 บทเรียนและลด HP ศัตรูจนหมดจึงชนะ ถ้าศัตรูยังไม่ตาย จะมีโจทย์ต่อพร้อมตราผนึกใหม่ที่ต้องแสดงด้วย print()
- ผิด 2 ครั้งแรกได้ฝึกฟรี ตั้งแต่ครั้งที่ 3 ศัตรูสวนทุกครั้งจนตอบถูก ไม่มีการจับเวลาอ่านโจทย์
- ตั้งรับใช้เพิ่ม 2 MP ลดดาเมจเข้า 60% และลดดาเมจออก 20%; อัศวินรับดาเมจปกติเบาลงอีก 15%
- มอนสเตอร์แต่ละชนิดมีท่าถัดไปแสดงบนหน้าจอ: พิษ เกราะ ใยลดพลัง ดูด MP/ฟื้น HP ชาร์จทุบหนัก และคำสาป
- เมื่อตาย กู้ภัยหักได้สูงสุด 15 เหรียญ กลับมาด้วย HP 70% และ MP 50% เพื่อป้องกันการติดเซฟที่เล่นต่อไม่ได้
- ความคืบหน้าบันทึกใน `localStorage` ของเบราว์เซอร์
- ปุ่มเสียงมุมขวาบนเปิดเพลงประจำฉากและเสียงโจมตี โดยเบราว์เซอร์จะเริ่มเสียงหลังผู้เล่นกดปุ่ม

## แนวทางพัฒนาต่อ

เพิ่มหรือแก้โจทย์ใน `curriculum.js` และปรับตัวตรวจคำตอบที่มีเลขข้อเดียวกันใน `python-worker.mjs` จากนั้นลองเล่นข้อที่เปลี่ยนจริงในเบราว์เซอร์ หากแก้ไฟล์ที่เบราว์เซอร์อาจแคช ให้เปลี่ยนเลข `?v=` ใน `index.html` และ import ของ `game.js`

เกมรันโค้ดที่ผู้เล่นพิมพ์ใน Web Worker ของเบราว์เซอร์พร้อมจำกัดเวลา การนำโค้ดผู้เล่นไปรันบนเซิร์ฟเวอร์ในอนาคตควรใช้ระบบแยกการทำงานที่ออกแบบสำหรับโค้ดที่ไม่เชื่อถือ

## แอนิเมชันและดนตรี v1.4

ท่ายืนใช้ภาพต้นฉบับสร้างเฟรม raster 24 เฟรมที่แคชไว้ต่อชนิดตัวละคร เท้ายึดกับพื้น ยกเว้นภูตที่ลอยได้ ตั้งรอบหายใจแยกตามอาชีพและมอนสเตอร์ และหยุดท่ายืนระหว่างโจมตี รองรับการลดการเคลื่อนไหวของระบบปฏิบัติการ โมดูลหยุดวาดเมื่อออกจากฉาก

เพลงแผนที่คงเดิม ส่วนการต่อสู้ใช้เพลงแต่งด้วย Web Audio จังหวะ 140–166 BPM มีเบส กลอง และท่อนคอร์ดวนสี่ห้อง โดยจัดเวลาบน audio clock เพื่อลดจังหวะสะดุด ไม่ต้องดาวน์โหลดไฟล์เสียงเพิ่ม เมื่อคำตอบถูก กล้องเลื่อนไปฉากต่อสู้และรอให้เลื่อนเสร็จก่อนเริ่มท่าโจมตี เมื่อจบเทิร์นจึงกลับไปโจทย์ถัดไป

แนวทางอ้างอิง: [Aseprite: Animation](https://aseprite.com/docs/animation/), [Pixel art Character Animations guide โดย Sandro Maglione](https://www.sandromaglione.com/articles/pixel-art-character-animations-guide)

## การต่อสู้และคัตซีน v1.5

เพลงต่อสู้เปลี่ยนเป็นเสียงบันทึกจริง 6 เพลงที่เปิดให้ใช้แบบ CC0 เพลงแผนที่คงเดิม ดูชื่อผู้แต่ง แหล่งดาวน์โหลด และรายละเอียดภาพ/ไอคอนใน [ASSET-CREDITS.md](ASSET-CREDITS.md)

`combat-cinema.js` จัดคัตซีนแยกอาชีพ (ข้ามได้ด้วยปุ่ม, Space, Escape) และจังหวะเตรียมตัว-เข้าปะทะ-กลับท่ายืน `sprite-motion.js` วาดท่ายืนและท่าลำตัวขณะโจมตีโดยยึดจุดเท้า `combat-rules.js` แยกกติกาที่ทดสอบได้ออกจากหน้าจอ รัน `node combat-rules.test.mjs` เพื่อตรวจสกิลมอนสเตอร์และตัวคูณความเสียหาย

เซฟเดิมเก็บดาว/เหรียญไว้ เมื่ออัปเกรดจาก v1.4 จะเริ่มทรัพยากรต่อเนื่องครั้งแรกด้วยพลังเต็ม แล้วรักษาคงเหลือหลังจากนั้น การเปลี่ยนอาชีพแปลงตามสัดส่วนเลือด/มานาเดิม จึงใช้เปลี่ยนอาชีพเพื่อเติมพลังไม่ได้
